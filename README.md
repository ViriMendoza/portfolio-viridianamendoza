# portfolio-viridianamendoza

Portafolio personal de Viridiana Mendoza, construido con React, TypeScript, Vite y Tailwind CSS.

## Desarrollo

```bash
npm install
npm run dev       # servidor de desarrollo
npm run build     # build de producción en dist/
npm run preview   # previsualiza el build
npm run lint      # ESLint
npm run format    # Prettier sobre src/
```
